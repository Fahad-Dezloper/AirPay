1. WALLET LINKING — the signature that carries your name to a second wallet
---------------------------------------------------------------------------
   Commit   : 71939f0
   Status   : 13/13 unit tests pass, including the replay attack. Never run against
              a real wallet, because creating a link needs a human to approve it.

   To run   : open a wallet that is NOT the Seeker one (tap its card in §2 → the
              sheet). The new "SEEN AS" panel should offer "Use dezloper.skr here".
              Press it.

   Expect   : the Seeker wallet opens, shows a READABLE sentence — not a
              transaction — beginning "AirPay wallet link v1". Approve it. The app
              returns, the panel flips to dezloper.skr with a tick and the line
              "Lent to this wallet by 4WZ9…D18D … Good until <date>".

   Watch for:
     - The app must come back to the wallet you STARTED on. Wallet.link() restores
       the previous selection in a finally block; if the selected wallet changes,
       that is the bug and the next payment would come from the wrong address.
     - Declining must change nothing at all. Log line: "— <wallet> did not sign".
     - signMessagesDetached is not signTransactions. If a wallet shows a
       transaction approval screen instead of text, the wrong call is being made.
     - Seeker Wallet is the only wallet this has to work on. Phantom and Solflare
       may not implement signMessagesDetached at all — if one refuses, that is
       worth knowing but is not a blocker, since the Seeker wallet is the one that
       holds the name.

   Then     : tap that linked wallet against the OnePlus. The payer should see
              "dezloper.skr" with a tick and the words "linked wallet" underneath.
              That is the whole point of the feature.

   NOT a concern any more: payload size. The link adds ~150 bytes and a unit test
   caps the card under 512B, but TESTING.md recorded maxTransceive=65279B measured
   on a real tap (2026-09-20), so there is no ceiling worth worrying about.
